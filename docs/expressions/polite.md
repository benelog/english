# 정중한 표현

원어민들이 일상생활과 직장에서 자주 사용하는 정중한 영어 표현 10가지(보너스 포함 12가지). '부탁할 때'와 '제안할 때'로 나누어 정리합니다.

## 무언가를 부탁할 때 (Asking a favor)

* **Could you / Would you...?** ([01:41](https://www.youtube.com/watch?v=6kCTDhW9rqQ&t=101)) — ~해주시겠어요? 가장 기본적이면서도 널리 쓰이는 정중한 부탁 표현.
    * Would you please tell me where the closest subway station is?
* **If you don't mind, would you...?** ([02:20](https://www.youtube.com/watch?v=6kCTDhW9rqQ&t=140)) — 괜찮으시다면, ~해주시겠어요? "If you don't care"라고 말하면 "네가 알 바 아니면"처럼 무례하게 들릴 수 있으니 반드시 "mind"를 사용.
    * If you don't mind, would you help put the dishes in the dishwasher?
* **If it's not a problem, could I (can I)...?** ([03:11](https://www.youtube.com/watch?v=6kCTDhW9rqQ&t=191)) — 문제가 되지 않는다면, 제가 ~해도 될까요?
    * If it's not a problem, could I call you back in ten minutes?
* **When you have a moment, can you (could you)...?** ([03:41](https://www.youtube.com/watch?v=6kCTDhW9rqQ&t=221)) — 시간 나실 때, ~해주실 수 있나요? 구어체에서는 "When you get a second"처럼 'get'을 사용하는 것도 자연스러움.
    * When you have a moment, can you email me those documents?
* **If you get a chance, could you...?** ([04:38](https://www.youtube.com/watch?v=6kCTDhW9rqQ&t=278)) — 혹시 기회가 되시면, ~해주시겠어요? 꼭 해야 하는 일이 아닌 부가적인 부탁을 할 때 사용. 꼭 해결해야 하는 일이라면 "When you get a chance".
    * If you get a chance, could you water our plants too?
* **By any chance, could you...?** ([06:21](https://www.youtube.com/watch?v=6kCTDhW9rqQ&t=381)) — 혹시라도 ~해주실 수 있나요? 상대방에게 수고가 많이 들어가는 큰 부탁을 할 때 사용하는 아주 정중한 표현.
    * By any chance, could you give me a ride home from work today?
* **I'd appreciate it if you would...** ([07:03](https://www.youtube.com/watch?v=6kCTDhW9rqQ&t=423)) — ~해주시면 감사하겠습니다. 상사나 선생님 등 '권위 있는 위치'에 있을 때만 사용. 동료나 배우자에게 쓰면 명령처럼 들려 기분을 상하게 할 수 있음.
    * I'd appreciate it if you would have the report done by this afternoon.

## 무언가를 제안할 때 (Giving suggestions)

* **What if we...?** ([08:10](https://www.youtube.com/watch?v=6kCTDhW9rqQ&t=490)) — 우리 ~하는 건 어때요? 정중하면서도 다소 직접적으로 대안을 제시할 때.
    * What if we reschedule for another day?
* **How about if we...?** ([08:50](https://www.youtube.com/watch?v=6kCTDhW9rqQ&t=530)) — 우리 ~하는 건 어떨까요?
    * How about if we go out to eat instead?
* **What do you think about...?** ([09:57](https://www.youtube.com/watch?v=6kCTDhW9rqQ&t=597)) — ~에 대해 어떻게 생각하세요? 상대방의 의견을 묻는 방식이라 간접적이고 예의 바른 제안 표현.
    * What do you think about this place?

## 보너스 표현 (Bonus Expressions)

* **You should probably...** ([10:44](https://www.youtube.com/watch?v=6kCTDhW9rqQ&t=644)) — 아마 ~하시는 게 좋을 것 같아요. 행동을 지시하는("Check the oven!") 대신 부드럽고 정중하게 권유할 때.
    * You should probably check the oven because I smell something burning.
* **I don't want to keep you** ([11:11](https://www.youtube.com/watch?v=6kCTDhW9rqQ&t=671)) — 더 이상 시간 뺏고 싶지 않네요. 대화를 끝내고 자리를 떠나야 할 때, 혹은 상대방이 바빠 보일 때 작별 인사를 시작하기 좋은 마법의 문장.
    * I don't want to keep you, but it was great talking with you.
